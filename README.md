# Smart Healthcare Microservices System

## Group Project

This project is a Smart Healthcare Microservices System developed using a microservices architecture.

### My Contribution
I was responsible for developing the Doctor Service module.

### Doctor Service Features
- Doctor Registration
- Doctor Profile Management
- Availability Management
- REST API Development
- MongoDB Integration
- Swagger API Documentation

### Technologies Used
- Node.js
- Express.js
- MongoDB
- Swagger
- REST APIs
- Microservices Architecture
